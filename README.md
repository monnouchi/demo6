# demo6

monの、水路と合奏で街を育てる小さな建設ゲーム試作です。正式なタイトルは未定です。

## 遊び方

1. 音あり／音なしを選んで開始。音は右上でいつでも切り替えられます。
2. **水路**を選び、泉からマスをクリック／タップ。押したままなぞると連続して引けます。
3. 水路の上下左右に**水車・雨樋・鐘・花園**を置きます。水車は木材、ほかの建物は街の彩りを育てます。
4. **楽器3種・動く建物6棟・流れる水路8マス・彩り60**で「小さな水の祝祭」を達成。その後も自由に街を作れます。

建設順は自由です。撤去で木材はすべて戻り、「ひとつ戻す」で直前の建設を戻せます。水が足りなくなると生産がゆっくりになるので、泉を深くしましょう。時々降る雨は水量と雨樋の彩りを増やします。

PC：`1`〜`6`で道具選択、盤面にフォーカスして矢印＋`Enter`で建設、`Ctrl/⌘+Z`で戻す、`M`でミュート。スマホはタップ／ドラッグで建設。盤面の`＋`で拡大、`移動`でドラッグ移動、`全体`で見渡せます。

街はブラウザに自動保存されます。右上の設定からJSONファイルで保存・読み込みもできます。ブラウザデータの削除や閲覧モードによって自動保存が使えない場合はファイル保存をご利用ください。

## 起動

Node.jsがあるMacなどで、このフォルダ内から `npm start` → <http://127.0.0.1:5176>。インストールやビルドは不要です。検証は `npm test` と `npm run check`。

GitHub Pagesは **Deploy from a branch → main → / (root)** で配信できる静的構成です。公開設定はリポジトリ所有者が行ってください。
