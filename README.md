# シーケンサータウン / Sequencer Town

monの、水路と楽器、木と花壇で自分の曲と街をつくる小さな作品。

[ブラウザで遊ぶ](https://monnouchi.github.io/sequencer-town/)

- **音を置く**：横16マスは2小節の8分音符、上ほど高い音。水車は低音、雨樋は滴、鐘は共鳴。同じ音階で自由に重ねられます。
- **水と風**：泉から水路をなぞり、上下左右に水車・雨樋を置くと水が届きます。鐘は水路なしで風に揺れ、響きます。街を渡る風が、置いた場所の音を鳴らします。建設費・水量・同拍の音数による制限はなく、密な和音は音量を整えます。配置と拍は天気で変わりません。
- **池をつくる**：水路を2×2以上に固めると、つながった水面になります。細い出入口は水路のまま。撤去・戻すで形も変わり、水・音の切替は各マスに使えます。
- **長屋の長い音**：水車・雨樋・鐘を同じ段・同じ種類で横につなぐと、先頭で一度鳴って長く響きます。水車と雨樋は持続、鐘は長い共鳴。水車・雨樋は1棟に水が届けば全体へ。鐘は給水なしで鳴ります。小節の境目はつながり、左右の端はつながりません。余韻は次の周回まで自然に残ります。
- **木と花壇**：配置した木は木質のコツ音、花壇は葉のシェイカー。水路なしで風に揺れて拍を刻みます。上ほど軽く明るい音、横並びは連打。背景の草は鳴りません。
- **歩く音符**：牛は柔らかな低音、ヤギは小さなカウベル。任意に置くと、風の一周ごとに空き地を一歩だけ歩き、次の周回の音が変わります。進んだ方向へ向き、止まった時は最後の向きを保ちます。水路・建物を通り抜けず、横につないでも長屋にはなりません。切替で音と歩みを止められます。保存には位置と歩みの状態も含まれます。動物は同じ一周で一度だけ鳴ります。
- **聴いて直す**：「移動」で泉・楽器→空き地。泉は一つのまま移動でき、元の場所にも音を置けます。「水・音の切替」で枝・楽器・植物をON/OFF。長屋も途中をOFF・移動・撤去で切り離せます。「戻す」で編集を取り消せます。決まった正解やクリアはありません。
- **音と写真**：音は操作して開始、右上でミュート。音を開始できない時も風と拍で遊べ、右上から再試行できます。メニューの「自分の音だけ」で伴奏を消せます。この選択も保存されます。メニューで調性と昼・夜を変更可。雨の植物は滴、夜の花壇は静かな虫の音色に。天気は晴れ／雨に固定、または自動で移ろいます。「街の写真」で街に寄る／全景のPNGを保存。対応端末では共有先を自分で選べます。
- **保存**：端末に自動保存、メニューでJSON保存・読込。改名前の街も、同じブラウザでは新しいURLへ引き継がれます。以前の作曲データは原本を保管して制限のない形式へ移行します。以前の花園と、水が届かず休止していた鐘は音OFFで維持。「水・音の切替」で参加させられます。さらに古い街は風景・JSON・写真を取り出せます。

PC・スマホ対応。道具の説明は選択名の「使い方」、遊び方と街の集計はメニューから。スマホの道具欄は横へスワイプ。初期配置のスマホは置きやすい拡大から開始。配置を変えた街の再開は全景から。拡大時は「動かす」で移動、「全景」で戻す。矢印＋Enterで建設、1〜9で道具、Mで音、⌘/Ctrl＋Zで戻す。

開発：Node.jsで `npm start` → <http://127.0.0.1:5176>。`npm test`、`npm run check`。依存ライブラリなしの静的アプリ。GitHub Pagesにはリポジトリのルートを使用。
