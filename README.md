# mon / demo6

水路を自由に引き、楽器の位置で2小節の合奏をつくる、小さな街づくり。正式タイトルは未定です。

[ブラウザで遊ぶ](https://monnouchi.github.io/demo6/)

- **水をつなぐ**：泉から水路をなぞり、上下左右に水車・雨樋・鐘を置きます。
- **位置で作曲**：横16マスが2小節の8分音符、上ほど高い音。同じ音階の中で、水車は低音、雨樋は滴、鐘は金属の余韻を鳴らします。「移動」で楽器→空き地を選び、拍や高さを変えられます。
- **水と余白を選ぶ**：木材は220の再利用予算、撤去で全額返却。水は晴れ12・雨16、水車と鐘は2、雨樋は1を使います。泉に近い楽器から鳴り、同じ距離なら上の段が先。同じ拍は3音まで。「水の切替」で枝や楽器を開閉し、鳴らす音を選びます。建設前の表示で水不足や拍の重なりを確認できます。
- **はじめの一曲**：ひとつ置いて移したら、4つの拍に3音色を届け、2小節を一周。達成後も自由に置き直せます。正解の旋律や水路はありません。
- **音と風景**：音は操作してから開始、右上でミュート。伴奏を消すと自分の音だけを聴けます。調性は街全体で変更できます。花園は音を鳴らさず水も使わない景観。雨粒・波紋・流路の色で雨が見え、泉に水が4足されます。
- **街の写真**：「建物に寄る／街の全景」を選び、操作欄のないPNGを保存。対応端末では共有先も選べます。SNSへの投稿は自分で選ぶ操作です。
- **保存**：この端末に自動保存。「遊び方と保存」からJSONの保存・読込もできます。以前の街の保存は残り、同じメニューから風景・JSON・写真を取り出せます。

PCとスマホに対応。拡大した盤面は「動かす」で移動、「全景」で戻せます。矢印＋Enterで建設、1〜8で道具、Mで音、⌘/Ctrl＋Zで戻す。

開発：Node.jsで `npm start` → <http://127.0.0.1:5176>。`npm test`、`npm run check`。依存ライブラリなしの静的アプリです。GitHub Pagesにはリポジトリのルートを使用します。
