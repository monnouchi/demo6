# mon / demo6

水路と楽器、木と花壇で、自分の曲と街をつくる小さな作品。正式タイトルは未定です。

[ブラウザで遊ぶ](https://monnouchi.github.io/demo6/)

- **音を置く**：横16マスは2小節の8分音符、上ほど高い音。水車は低音、雨樋は滴、鐘は共鳴。同じ音階で自由に重ねられます。
- **水と風**：泉から水路をなぞり、上下左右に楽器を置くと水が届きます。街を渡る風が、置いた場所の音を鳴らします。建設費・水量・同拍の音数による制限はなく、密な和音は音量を整えます。雨は風景を変え、曲はそのままです。
- **長屋の長い音**：同じ段・同じ楽器を横につなぐと、先頭で一度鳴って長く響きます。水車と雨樋は持続、鐘は長い共鳴。1棟に水が届けば全体へ。小節の境目はつながり、左右の端はつながりません。余韻は次の周回まで自然に残ります。
- **木と花壇**：配置した木は木質のコツ音、花壇は葉のシェイカー。水路なしで風に揺れて拍を刻みます。上ほど軽く明るい音、横並びは連打。背景の草は鳴りません。
- **聴いて直す**：「移動」で楽器→空き地。「水の切替」で枝・楽器・植物をON/OFF。長屋も途中をOFF・移動・撤去で切り離せます。「戻す」で編集を取り消せます。決まった正解やクリアはありません。
- **音と写真**：音は操作して開始、右上でミュート。「自分の音だけ」で伴奏を消せます。調性と昼・宵を変更可。「街の写真」で建物に寄る／全景のPNGを保存。対応端末では共有先を自分で選べます。
- **保存**：端末に自動保存、設定でJSON保存・読込。以前の作曲データは原本を保管して制限のない形式へ移行します。以前の花園は音OFFで維持。「水の切替」で参加させられます。さらに古い街は風景・JSON・写真を取り出せます。

PC・スマホ対応。スマホの道具欄は横へスワイプ。拡大時は「動かす」で移動、「全景」で戻す。矢印＋Enterで建設、1〜9で道具、Mで音、⌘/Ctrl＋Zで戻す。

開発：Node.jsで `npm start` → <http://127.0.0.1:5176>。`npm test`、`npm run check`。依存ライブラリなしの静的アプリ。GitHub Pagesにはリポジトリのルートを使用。
